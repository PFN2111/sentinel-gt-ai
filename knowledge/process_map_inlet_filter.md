# Process Map — Inlet Filter Differential Pressure

## Decision flow
1. Read inlet differential pressure against load and ambient temperature.
2. A slow rise on both is filter fouling. Plan a filter change.
3. A step, a flat line, or a reading that ignores load is a transmitter fault.
4. Do not call fouling from one spiked sample.

## Quick checks
- Differential pressure versus load
- Ambient temperature on the same window
- Compressor discharge pressure moving with the inlet loss
